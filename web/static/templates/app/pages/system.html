Safe maintenance

VACUUM compacts SQLite; backups use SQLite's consistent VACUUM INTO mechanism and are verified before registration.

Restore is intentionally offline: stop the container, preserve the current database, and replace it with a verified downloaded backup. This avoids swapping a database underneath active workers.

If proxy credentials are configured, preserve the adjacent .proxy-master-key too. Database backups contain encrypted proxy URLs, but never copy the encryption key into the database or download.
