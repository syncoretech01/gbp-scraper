Safe maintenance

Every mutation is CSRF-protected and confined to the mounted local data directory.

Export redacted diagnostics

Recycling pauses each active job at a safe boundary, which tears its browser workers down, then resumes it from the stored checkpoint. No committed result is discarded and no process is started for you.

A full process restart stays an explicit Docker operation. Prepare a restore below to prove a backup is usable and stage it; then stop the container, replace jobs.db with the staged file, and keep .proxy-master-key in place.

Local self-test

Checks database reads/writes, output storage, memory, disk, worker heartbeat, the Playwright browser driver, proxy credentials, and optionally public network reachability. Driver and proxy results are advisory: only a real scrape proves a browser launch or end-to-end proxy access.

Network checks run only when explicitly selected.
