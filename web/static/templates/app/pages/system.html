Safe maintenance

Every action is CSRF-protected and confined to the mounted data directory. None of them deletes a collected result.

  • Check database integrity

    Reads every page of jobs.db and reports corruption. Changes nothing.

  • Compact the database

    Rebuilds the file to reclaim free pages. Active database work waits briefly.

  • Clear the map tile cache

    Removes only cached OpenStreetMap tiles. They are re-fetched on demand.

  • Stop every job safely

    Requests a checkpointed stop for all queued and active jobs. Committed results are kept.

  • Recycle workers

    Pauses each active job at a safe boundary, tears its browsers down, then resumes from the stored checkpoint. No committed result is discarded and no process is started for you.

  • Clear browser profiles

    Deletes the reusable Chromium profiles ({{.Page.BrowserProfile}} of cookies and site data). The next run starts cold.

  • Clean old artifacts

    Deletes only unregistered files older than the chosen age from one contained directory.

A full process restart stays an explicit Docker operation. Prepare a restore below to prove a backup is usable and stage it; then stop the container, replace jobs.db with the staged file, and keep .proxy-master-key in place.

Local self-test

Checks database reads and writes, output storage, memory, disk, the worker heartbeat, the Playwright browser driver, and proxy credentials.

Launch a test browser really starts a headless Chromium with the scrape engine's hardening flags, so it tells you whether Thorough-mode scrapes can run on this machine; it takes a few seconds. Proxy and network results stay advisory — only a real scrape proves end-to-end access. Network checks run only when you pick them.
