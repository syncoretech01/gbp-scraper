Python, JavaScript, and Go
# Python
requests.get("{{.Page.BaseURL}}/api/v1/results?q=dentist", headers={"Authorization": "Bearer " + key})

// JavaScript
fetch("{{.Page.BaseURL}}/api/v1/results?q=dentist", {headers: {"X-API-Key": key}})

// Go
req, _ := http.NewRequest("GET", "{{.Page.BaseURL}}/api/v1/results?q=dentist", nil)
req.Header.Set("Authorization", "Bearer "+key)

Security scope

Same-origin browser sessions remain usable with CSRF. Once one API key is enabled, scripts must send a read-only or full-access key. Rate limiting is local and request logs never retain headers, bodies, or query strings.

{{end}}
