The scheduler is local

It checks due work every second while the application is running. Jobs enter the same durable queue and retain ordinary pause, recovery, partial-result, and export behaviour. Failed runs retry automatically inside each schedule's retry budget, completed runs can produce an automatic export, and old run history is pruned per schedule.

Create schedule

Save a scrape template first, then choose its local recurrence.

Numbers, comma lists, and * are supported.

Automation

0 disables automatic retries; at most 10.

Waits backoff times the failed attempt number.

0 keeps every run of this schedule.
